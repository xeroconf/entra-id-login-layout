# entra-id-login-layout
Modernizes the boring default Azure sign-in page for your tenant.

Documentation on how to customize the branding [here](https://learn.microsoft.com/en-us/entra/fundamentals/how-to-customize-branding).
Only supports the full-screen background layout.
> ⚠️ **Microsoft Note:** Custom CSS for company branding is only available for tenants created **before January 5, 2026**. Tenants created after this date will not support custom CSS.
